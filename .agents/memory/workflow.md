- 2026-10-30: A feature or bug fix ends with a closeout pull request after the main one merges: the backlog item is closed with the pull request reference and the measured numbers, and the plan gets its status log and results.
- 2026-10-30: GitHub tools append a "Generated by" footer to pull request bodies. Create the pull request, read it back and replace the body with the clean text through the same API; read it back again. A body edited through a raw REST PATCH got the footer again; an edit through the GitHub tool's update call sticks.
- 2026-11-06: Force-push can be refused in cloud sessions; bring `main` into a feature branch with a merge instead of a rebase.
- 2026-11-06: A cross-project reply is written to the other project's `aurora/inbox` branch, so the session needs push access to that repository (in a cloud session, add the repository first).
